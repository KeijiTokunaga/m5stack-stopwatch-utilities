# Paradise — StopWatch育成ゲーム仕様・操作

ユーザー提示のTamagotchi Paradise仕様をもとに作成した、StopWatch C152向けの独立した育成ゲーム。公式ファームウェアの再現・解析結果を称するものではない。初期フィールドはユーザー指定の「りく（Pink Land相当）」。本体は既存のStopWatchを使用し、単4電池・Cボタン・ズームダイヤル・専用ドッキング端子は追加しない。

## 起動と操作

黄色長押し → アプリ選択 → **Paradise**。初期画面で誕生日・言語・日時を設定でき、「はじめる」で卵と惑星を生成する。初期資金500G、惑星名PARADISE。実際の誕生日は未指定なので初期値1月1日を変更して使う。

| 操作 | 動作 |
|---|---|
| 黄色短押し | 項目を順送り |
| 青色短押し | 決定・お世話・ゲーム操作 |
| 青色長押し | C相当の戻る。ホームでは1段階ズームアウト |
| 画面下のSPACE / FIELD / PET / CELL | 4段階のズームを選ぶ |
| 画面上部をタップ | ラボを開く |
| 緑の選択カードをタップ | 現在の項目を実行 |
| 黄色長押し | 統合アプリの一覧へ戻る |

大きなキャラクターは独自の図形描画。公式の画像・ドット絵の複製ではない。日本語／英語で操作ラベルを切り替えられる。種名など一部の固有名詞は日本語。

## 階層別機能

- **SPACE**：惑星情報、宇宙トラベル、所持デコ設置、通信の未対応表示。
- **FIELD**：そうじ、解放済みフィールド切替、火山／泉エッグハント、遊具設置、アダルトを放す。
- **PET**：属性別ごはん／料理、おやつ、4種のお遊び、お手入れ、消灯／点灯、死神の追い払い、ベビーの成長確認。
- **CELL**：1匹ずつ治療、ステータス、環境・栄養・MAX・ミスマークの数値確認。
- **LAB**：情報、6種のラボゲーム、ショップ、シッター、候補4体とのお見合い、図鑑、未対応ラボコード案内、設定。

調理はショップ末尾の項目から。同属性食材2個を料理1個へ変換（Lv5）。デコ売却もショップ末尾。惑星名は英大文字・数字・ハイフン等の16文字以内。名入力は黄色で文字選択、青で追加、画面下で削除／保存。日時入力は黄色で増加、青で次の欄。存在しない日付は確定しない。

## 生体と時間

| 項目 | この版の確定値 |
|---|---|
| 孵化 | 開始後1分 |
| 満腹／機嫌 | 0〜4。ベビーは3分、以降は20分で各1減少 |
| 呼び出し | 空腹0・機嫌0・病気の条件で発生、20分未対応でミス。一度確定した未解消条件を毎分重複加算しない |
| MAX回数 | 4未満から4に回復した時だけ加算。満タン連打で増やせない |
| 排泄 | 起きている間60分ごと、最大4個。まとめて管理し最古の排泄から30分未満なら1個25%の燃料 |
| 発病 | 排泄物を60分放置、または空腹呼び出し15分以上など。ウイルス3匹 |
| 治療 | CELLで青1回につきウイルス1匹を治す |
| 死神 | 病気を起きた状態で120分放置すると出現、10分で死亡。PETの追い払いを10回実行後、CELLで治療 |
| 睡眠 | 19〜21時の手動消灯、22時強制睡眠、6〜9時の手動点灯、10時強制起床 |
| 睡眠・シッター | 満腹／機嫌低下、病気、呼び出し猶予、排泄、防衛イベント進行を停止。年齢・成長時間は進む |
| シッター | 6〜18時、300G。19時退出。退出後のお迎えで機嫌1減少 |
| お手入れ | 1日1回、機嫌1回復 |
| 隕石 | 起きている間6時間ごと。約2分で被弾。ラボ「いんせきパンチ」で5回中3回以上成功すると迎撃 |

仕様に幅・未指定がある時間や費用は上記をこの版の設計値とした。古い「ゆめたま」の寿命や保存状態は継承しない。

他アプリ表示中も育成が進む。Wi-Fiでシステム時刻が同期済みなら、再起動後に電源OFF中の経過も反映する。時刻不明時はゲーム内部の仮の正午から進め、最初の時計同期は経過時間として扱わない。正しい生活サイクルのため初回に日時設定またはWi-Fi同期を行う。時計の巻き戻しや手動修正で過去分を再加算しない。時計の修正で経過時間を水増ししないよう、ゲーム側の時刻も修正地点へ合わせる。

## 成長・進化・遺伝

- ベビー：同一フィールド15分ごとに環境マーク。4個と「成長を確認」でキッズ。ベビー中のフィールド切替でマークをリセット。4時間経過して4個未満なら「でかべびまるっち」。この特殊個体は移動・放逐・交配不可。
- キッズ：24時間でヤング。食材1点／料理2点、5点で栄養マーク、最多の系統で科を選択。同数ならペレット優先、残りは先の属性を優先。
- ヤング：24時間でアダルト。S＝ミス0かつ両MAX5回以上、A＝ミス0〜1、B＝2〜5、C＝6以上。
- この版は陸・水・空の12科×4ランク＝48種の名前と特殊1種を収録。育てたアダルトを図鑑へ記録。全カラーの68種以上を収録したという扱いにはしない。
- 目51パターン／体色16色。交配では両親それぞれの目と色を独立選択し、4組み合わせを等確率で継承。形状は属・科に応じた独自の描画。
- アダルト放逐で各フィールド最大4体の住民となり次世代へ。新しい卵・放逐は確認画面を経由する。
- お見合いは4候補。相性は初回40%、同候補再訪で15%ずつ増加、両ゲージ満タンで20%加算、上限95%。1日3回失敗で停止。候補入替で個別相性はリセットするが当日失敗数は保持。

## 経済・ミニゲーム・探索

- 無料ペレット、食材50G、料理100G、おやつ20G、遊具200G、デコ売却500／600／700G。
- ラボゲームはLv1から、睡眠中も遊べる。機嫌は変えず星1〜3で100／200／300G。Lv9のHARDでは200／400／800G。
- ミルク：黄色・青を交互入力する10秒ゲーム。ジャンプ／そうじ／隕石／おさんぽ：移動マーカーが中央へ来た時に青を押す5ラウンド。お料理／ほこり／こっちむいてホイ：対象番号を黄色で選び青で決定。旗上げ：旗の色と同じボタン。UFO：最初の1.2秒の対象を記憶して選択。
- 元仕様のゲーム名・目的を元にしたStopWatch用の簡易ルール。専用ダイヤルの操作感、障害物ステージ、2画面ゲームを完全再現するものではない。
- エッグハントは昼間、1個体1日1回。育成中個体と利用可能な住民、足りなければ白いNPCで必ず3体の自動編成。満機嫌なら10%で食材9個、それ以外は1〜5個。火山はたんぱく系、泉は植物系の食材。
- 燃料100%かつLv6で宇宙トラベル。Lv6は3種のデコ、Lv7〜9で種類が追加、Lv10で全解放。旅の演出と目的地は簡略化して抽選で持ち帰る。

## 惑星レベル

キッズで1、ヤングで2、初アダルトで3、世代交代で4、第2フィールドへ切替で5。以降累計アダルト2／3／4／5／6体で6／7／8／9／10。Lv4で水、Lv6で空を解放。レベルは下がらない。

## 保存・検証

NVSの `paradise` 名前空間へ操作時と60秒ごとに保存。世代・住民・所持品・図鑑・設定を含むスナップショットを二つのスロットへ交互保存し、版・サイズ・チェックサム・値の範囲を確認して最新の有効な記録を復元する。片方だけ破損なら残る記録を使用、両方破損なら保存エラーを画面に表示してユーザーの新規開始を待つ。電源断で最大約60秒の操作進捗を失う可能性がある。標準のフラッシュ配置を維持し、旧ペット用パーティションを上書きしない。

`firmware/test/paradise.cpp`：状態遷移・睡眠・呼び出し・治療／救助／死亡・成長・ランク・経済・探索・遺伝・保存破損・ミニゲーム・更新頻度の独立性・10万分のランダム耐久試験。

USB診断115200 baud：`?` は版・育成段階・レベル・保存連番、`P` はParadise画面を開く（新規開始はしない）、`F` は画面バッファのRGBデータ取得（FRAME_RGBヘッダー後466×466×3バイト）。

## 明示的な対象外・相違点

- 専用機ドッキング、別カラー端末の識別、通信シークレット、2画面協力／対戦、規則未提示の8桁ラボコードは未実装。
- Orange／White／Jade専用フィールド・キャラクター・セラピーチ・フィールド拡張は今回選択のPink相当には含めない。
- 体重、専用機の細かなアニメーション、全25コマンドの配置の完全一致、スタッフロール、公式惑星デコの画像は再現しない。表示・入力・ゲームのルールはStopWatch向けに調整した。
- 公式取扱説明書や実測解析に基づく仕様と独自に検証したという主張はしない。提供された仕様が設計の出発点。

- 育成モデルの境界テスト、10万分ランダム耐久試験、AddressSanitizer／UndefinedBehaviorSanitizer検証成功。既存ロジック・ポモドーロ・天気・時計・モーションのホストテスト成功。
- USB書き込みとハッシュ照合成功。StopWatch自動検出、v1.4.0の起動応答を確認。
- 実機の画面バッファから日本語の初期画面を取得し、表示を確認。物理ボタンの全操作や、実時間で数日にわたる育成は未確認。
